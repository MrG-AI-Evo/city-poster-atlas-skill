# 城市海报图鉴 / City Poster Atlas

把任意城市或旅行目的地转化成一张有当地辨识度的竖版水彩拼贴旅行海报。

这个 Skill 适用于中国城市与全球目的地。它会围绕一个明确的主场景，组织地标、生活气息、标题、坐标、关键词和纸张肌理；当你提供完整样板提示词时，它优先保留原样板的构图、信息层级、文字位置和视觉密度，只替换城市事实。

## 适合做什么

- 城市、海岛、古城、街区、地标的旅行海报
- 水彩插画、照片拼贴与现代编辑设计混合的竖版视觉
- 延续既有样板风格的城市系列海报

它把“必须锁定”的主场景、地标和文字信息，与可以自然发挥的人群、树木、飞鸟、船只、服装和倒影分开处理，避免画面变成景点堆叠。

## 安装

把本仓库中的 `city-poster-atlas` 文件夹复制到你的 Codex Skills 目录，或直接让支持本地工作区的 AI 工具读取该文件夹中的 `SKILL.md`。

例如，在对话中调用：

```text
$city-poster-atlas 创作一张陕西西安的水彩拼贴旅行海报，主场景是大雁塔，并带有大雁塔广场或大唐不夜城的元素。
```

## 使用方式

直接说清四件事：地点、主场景、必须保留的地标或元素、希望出现在海报上的文字。也可以贴上一份完整的参考提示词，并说明希望“严格适配样板”。

示例：

```text
$city-poster-atlas 为圣托里尼制作一张竖版水彩拼贴旅行海报。
主场景为伊亚日落和火山口海景；保留蓝顶教堂、白色悬崖建筑和爱琴海。
标题为“圣托里尼 2026”，副标题为“爱琴海的白与蓝”。
```

## 输出原则

- 优先让人一眼看出地点，而不是堆砌景点。
- 完整样板优先：保留其结构、文案位置、构图关系与气质。
- 人物与环境动态用于增加真实感，不抢主场景和地标的视觉重心。
- 海报文字会作为生成提示的一部分；如需精准排版，可在生成后进行设计软件精修。
