# 城市海报图鉴

为国内外城市与旅行目的地创作兼具现代旅行海报、照片拼贴和水彩插画质感的竖版视觉。适用于单张海报、生图提示词，或将已有城市样板严格改写为另一地点。

## 先选择模型，再开始推理

在检索、构思、撰写提示词或调用线上生成服务前，先用下列规则确定本次模型。把选择结果作为内部工作设置，并以一句简短说明告知用户。

| 任务情况 | 模型与推理强度 |
|---|---|
| 用户已提供城市、场景和文案；只需整理、改写或产出标准提示词/版式 | GPT-5.6-sol，低或中 |
| 需要查证若干地标、协调 3–5 个空间元素、或提出原创但常规的构图方案 | GPT-5.6-sol，中或高 |
| 需要在多版视觉方向中权衡、处理复杂的地理连续性、或反复诊断生成结果 | GPT-6，中或高 |

不得因为任务含图片就默认升级到 GPT-6；只有最后一行的复杂度明确成立时才升级。不得使用 Pro，也不得以本地推理作替代。若执行环境不能切换模型，仍按此分级估算工作量并在当前可用的线上模型中采用最接近的设置。

## 选择工作模式

先判断用户是否给了完整的参考提示词、海报样图，或明确说“按这个版本改”。两种模式不能混用：

### 模式 A：样板复刻（优先）

当用户提供的参考中已经包含场景、元素位置、文案、年份、坐标与风格时，视为创作规格，而不是灵感来源。必须：

1. 按“场景 → 前景/中景 → 背景 → 自然与光线 → 设计元素 → 叠加效果 → 风格”的原始顺序逐项列出锁定项。
2. 只替换与目标城市冲突的事实：城市名、主地标、地理要素、坐标、短标语与关键词。保留原样板的画幅、时段、叙述密度、文字层级、每个元素的相对位置与风格用词。
3. 将元素分为两层：**锁定层**是主场景、主地标、相对方位、图中文字与风格；**现场状态层**是慢跑者、散步游客、街头人流、服饰、灯笼、树木、鸟群、倒影等氛围细节。现场状态层可按城市真实感自由发挥，但不得抢走主地标、改变整体时段，或凭空加入新的主要地标。
4. 让替换后的锁定层在真实空间中合理相邻；这是事实校验，不是重构构图的理由。
5. 用户的样板包含图内文字时，输出的主提示词也必须包含同等完整的图内文字和位置。不得自行改成“无字底图”。可以额外给一份无字后期版本，但不能替代主版本。
6. 若样板有中文和英文两个版本，两个版本都交付，且字段、方位和数量一一对应。

输出前用“锁定项 / 目标城市替换项 / 状态”简表做一次**逐句覆盖核对**：开头、主场景与方位、背景主句、5 个文字区、叠加效果句和风格句均须标记为“保留并替换”或“用户明确删去”。现场状态层记录为“保留”或“城市化发挥”，不按逐字复刻判定。不要把这份内部制作记录放进海报画面。

### 模式 B：原创或无字底图

仅在用户没有提供完整样板，或明确要求“原创”“无字底图”“后期排字”时启用。此模式才可以使用可编辑文字安全区、无字生成和扩展构图建议。不要把模式 B 的惯例反向施加到模式 A。

## 确定地点锚点

从用户给出的地点、旅行主题、季节或时间中提炼一个明确的主场景。原创模式优先使用 3–5 个能辨识地点的视觉锚点：滨水空间、地标建筑、地形、交通工具、植被或当地生活片段。样板复刻模式则以样板的元素数量和层级为准。不要把地标拼成互不相邻、无法共存的景观；远景可简化为轮廓。

若用户未提供资料，对可能变化或易混淆的地标、坐标、译名、当地语言写法和交通工具先查证。地理与政治表述遵照用户提供的称呼，并避免无关的政治化扩写。

## 构图与氛围（仅原创模式可自由发挥）

- 默认竖版，留出清晰的上方标题区、左右角信息区和底部手写签名区；画面呼吸感优先于堆满元素。
- 以黄金时刻的暖光为基础，加入青色与米色纸张肌理、半透明几何块、水彩晕染与飞溅。水面或玻璃可承接夕阳和城市灯光倒影。
- 使用前、中、远景建立层次：近景人物或步道，中景交通与水面，远景天际线/山体。人物应是自然生活切片，避免摆拍式密集人群。
- 保留地域特征；不要因“赛博”“现代”标签而擅自加入不对应城市的霓虹、轨道列车或建筑。

## 线上生成与文字的分工

仅使用可访问的**在线图像生成服务**进行生成或编辑；不得运行、安装或调用本地推理模型、ComfyUI、本地扩散工作流或本地 GPU 推理。模型和推理强度必须遵循上节的前置分级；服务不可用时，交付提示词与排版方案，不以本地生成替代。

图像模型对中文长文本和精确排版不可靠，但这不是省略用户指定文字的理由。在**样板复刻模式**，主提示词必须保留用户要求的图内文字与布局，并明确要求正确拼写；如有需要，可在主版本之后补充一份同构图的无字底图提示词，供后期排字。在**原创模式**，默认生成无可读文字的底图。

当用户需要完整方案，交付：

1. 一条中文生图提示词和一条英文生图提示词；二者保持同一事实、构图与图内文字。样板复刻时，保留样板的段落结构和信息密度。
2. 一份逐区域文案清单；样板复刻时，采用样板已有的区域、层级和文案数量，不擅自增删。
3. 简短反向提示词，排除乱码、水印、错误地标、畸形人物、过度拥挤、低清晰度与不相关国旗/政治符号。

若主版本含图内文字，简短说明生成后仍可校正文字，但不要把该提醒变成拒绝生成文字的理由。

## 默认信息架构

在原创模式中，将以下内容替换为用户确认的资料，不要虚构年份、坐标或宣传口号。样板复刻模式以用户的样板信息架构为准。

- 左上：`{城市} {年份}`；下一行短标语。
- 右上：竖排中文 `{城市}`；下方 `{CITY} {REGION}`。
- 左下：`{纬度} N {经度} E`、`{CITY} {REGION}` 与简洁波浪图标。
- 底部中间：手写体 `{城市}`。
- 右下：4–6 个城市关键词的竖排中文列表。

严格复刻的中英文提示词样板见 [references/prompt-template.md](references/prompt-template.md)。

## 交付前检查

核对主场景、地标、交通工具、坐标、译名和文案是否均属于目标城市；确认风格元素没有遮挡关键主体或文字安全区。若海报将实际发布，使用真实来源的参考图并确认其授权范围。
